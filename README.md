# Bus Reservation System

A Java-based desktop application developed using **Java Swing** for managing bus reservations. Users can register and log in, select routes and dates, book tickets, view their bookings, and cancel reservations.

### Features

* User registration and login
* Multiple bus routes and travel dates
* Ticket booking with passenger details
* Automatic seat availability management
* View personal bookings
* Cancel selected bookings
* Graphical user interface using Java Swing

### Technologies Used

* Java
* Java Swing
* AWT
* Collections Framework
* Event Handling
* CardLayout

### Concepts Used

Object-Oriented Programming, HashMap, ArrayList, GUI Components, Event Listeners, and Data Management.
